# Programação Web

Repositório com atividades acadêmicas desenvolvidas durante a disciplina de Programação Web no curso de Análise e Desenvolvimento de Sistemas da FATEC Sorocaba.

## Objetivo

Praticar conceitos de desenvolvimento web, estruturação de páginas, estilização, lógica com JavaScript, manipulação do DOM e criação de interfaces simples.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Visual Studio Code
- Git e GitHub

## Aprendizados

Durante a disciplina, pratiquei estruturação de páginas web, estilização com CSS, lógica de programação com JavaScript, manipulação de elementos HTML e organização de arquivos em projetos acadêmicos.
